# 模架工装智能管理系统原型

这是模架工装智能管理系统 Web 端高保真原型的 GitHub 部署仓库。

## 当前版本

- 版本：v1.5
- 重点能力：资产地图、仓库库区库位、BOM 多级结构、产品分类层级表、悬浮配置面板、版本快照
- 本地启动：`npm start` 后访问 `http://127.0.0.1:4173/`
- 最近发布触发：2026-05-27

## 说明

GitHub Pages 适合跨电脑访问同一个原型网址。页面内配置默认保存在当前浏览器中；如果要做到公司电脑修改后家里电脑继续编辑，需要额外接入在线数据库或后端保存服务。

本地完整工程支持 `server.js` 保存配置接口，后续可继续接入在线存储并生成 PRD Word 文档。
